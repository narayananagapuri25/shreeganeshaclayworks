# Shree Ganesha Clay Works

A mobile-first digital showroom for traditional clay products, based in Mancherial, Telangana.

## First release

- Static, dependency-free website suitable for Cloudflare Pages or GitHub Pages.
- Responsive product catalogue with category filtering and search.
- Product-specific WhatsApp enquiry links (no checkout or payment collection).
- English/Telugu language toggle.
- Store location, phone contacts, and visit information.

## Before public launch

1. Replace representative catalogue imagery with photographs of the shop's actual products.
2. Confirm which phone number should be the primary WhatsApp ordering number.
3. Verify the catalogue, product availability, delivery/pickup details, and Telugu copy with the shop.
4. Add the final logo and social links supplied by the owner.

## Local preview

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript; no build step is required.
